XOutput: Garante que o Windows trate cada controle como um dispositivo XInput distinto, facilitando o trabalho da xinput1_3.dll em redirecionar os slots.

Xpadder: Atua na camada de mensagens da janela, garantindo que o foco e os comandos de menu fiquem "presos" à instância correta.

Multiplayer.dll: Consolida tudo vinculando o HWND de cada janela ao seu respectivo Player ID, impedindo que um controle "vaze" para a tela do outro.

JoyXoff: recurso extra bonus.

Todos esses recursos, assim como o dxwnd, são trabalhos de terceiros usados no projeto como complementos integrados e funcionais para comportamento de janelas, entradas e saidas.
