Atualização de webviewtkiter para webview2 usando o motor do edge portatil e embutido com susporte a CSS3 e HMTL5, usando as dependencias do pythonet e pywebview que so estão disponiveis para a versão do python 313. Como usamos o versão 314, havia limitações que nós obrigava a usar o webviewtkiter. O webview2 é um recurso valioso para estilizar o customtinker para manuais, links e navegação offline, possibilitando usar outros recursos e tools com python, csse html juntos.
