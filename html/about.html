Manifesto Splitbox Alpha

Versão Atual: 1.7.2

O Splitbox é um orquestrador de processos e isolamento de janelas otimizado para Kernel Isolation, parte integrante do RV Project.

Tecnologia de Forja

  • Interpretador: Python 3.13 (Ambiente lorde)
  • Motor Web: webviewtkiter
  • Interface: CustomTkinter Dark | Blue Theme
